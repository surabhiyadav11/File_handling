# RAAD Subject Programs

This repository contains C++ implementations of different problem statements from RAAD coursework. Each program demonstrates data structures, sorting, and CRUD operations in practical scenarios.

## 1. Logistics Operating System
- **Concepts:** Structures, bubble sort, formatted output
- **Features:**
  - Sort packages by deadline (Emergency Mode)
  - Sort packages by distance (Fuel-Saving Mode)
  - Sort packages by shipping cost (Revenue Mode)
- **Learning Outcome:** Applying sorting algorithms to real-world logistics scheduling.

## 2. Dictionary using Doubly Circular Linked List
- **Concepts:** Linked lists, dynamic memory, CRUD operations
- **Features:**
  - Insert new word with meaning
  - Delete word
  - Update meaning
  - Display dictionary contents
- **Learning Outcome:** Understanding circular linked list operations and data management.

## 3. Mall Purchase Pattern
- **Concepts:** Classes, vectors, maps (STL)
- **Features:**
  - Add products to mall inventory
  - Record purchases
  - Display purchase frequency
- **Learning Outcome:** Using STL containers to track and analyze purchase behavior.
